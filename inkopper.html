Eerste keer: Application Password aanmaken
  1. Log in op WordPress → Gebruikers → Jouw profiel
  2. Scroll naar Application Passwords
  3. Geef het een naam (bijv. Kop) en klik op Nieuw application password toevoegen
  4. WordPress toont eenmalig een 24-tekens code (xxxx xxxx xxxx xxxx xxxx xxxx) — kopieer 'm en bewaar in je password manager
  5. Vul site-URL en gebruikersnaam in (worden onthouden); plak het password — het wordt niet opgeslagen, je password manager kan het volgende keer invullen
